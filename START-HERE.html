PolotskVet: GitHub → Vercel

Пошаговый запуск красной версии сайта Романа Чертопалова. Подготовлено 13 ноября 2026 года.

Результат: код хранится на GitHub, Vercel публикует сайт и даёт ссылку для просмотра. Устанавливать Node.js, запускать сборку или пользоваться терминалом для этого способа не нужно.

Сейчас можно разместить страницу для согласования дизайна. Номер телефона ещё не получен: кнопки записи показывают сообщение об этом. Домашние услуги и цены нужно подтвердить у Романа. Индексация закрыта до рабочего запуска.

1. Распакуй архив

  1. Скачай polotskvet-site.zip и распакуй двойным кликом.
  2. Открой папку polotskvet-site.
  3. Проверь, что внутри лежат public, docs, inputs, design-assets, README.md, AGENTS.md и vercel.json.
  4. Для локального просмотра открой public/index.html двойным кликом. Оставь папку assets рядом с остальными файлами внутри public.

На GitHub нужно загрузить содержимое папки polotskvet-site, сохранив вложенные папки. После загрузки vercel.json должен быть виден в корне репозитория.

2. Создай репозиторий на GitHub

Git — система версий; GitHub — сервис, где будет храниться этот проект. Начнём через браузер.

  1. Войди в GitHub или создай аккаунт.
  2. Открой создание репозитория.
  3. В Repository name введи polotskvet-site.
  4. Выбери Private, если исходники не должны быть общедоступными. Это не мешает Vercel публиковать сам сайт.
  5. Оставь выключенными добавление README, .gitignore и лицензии: нужные файлы уже подготовлены.
  6. Нажми Create repository.

3. Загрузи файлы

  1. На странице пустого репозитория нажми uploading an existing file. Если в репозитории уже есть файлы: Add file → Upload files.
  2. В Finder открой распакованную папку polotskvet-site и выдели всё её содержимое: папки и файлы.
  3. Перетащи выделенное в область загрузки GitHub. Сам ZIP и внешнюю папку целиком перетаскивать не нужно.
  4. Дождись загрузки всех файлов. В списке должны быть пути вроде public/index.html, public/assets/brand/polotskvet-logo.png и vercel.json.
  5. В сообщении коммита напиши Initial PolotskVet website и нажми Commit changes.
  6. На главной странице репозитория проверь: public и vercel.json находятся на одном уровне. Внутри public лежат index.html, styles.css, app.js и assets.

GitHub допускает до 100 файлов за одну браузерную загрузку и до 25 MiB на файл. Этот комплект укладывается в эти ограничения. Инструкция GitHub.

4. Подключи Vercel

  1. Открой Vercel и войди через GitHub: Continue with GitHub.
  2. Выбери команду/аккаунт, где будет жить сайт. Для сайта, рекламирующего платные услуги практики, нужен Pro или другой тариф с коммерческим использованием. Hobby предназначен для личных некоммерческих проектов. Условия использования тарифов.
  3. На панели Vercel нажми Add New → Project; в некоторых экранах кнопка называется New Project.
  4. В разделе Import Git Repository найди polotskvet-site.
  5. Если его не видно, подключи GitHub через Install / настройку GitHub App и разреши доступ к этому репозиторию. Для private-репозитория это также необходимо.
  6. Нажми Import рядом с polotskvet-site.

5. Проверь настройки и нажми Deploy

Большая часть настроек уже записана в vercel.json.

Настройка Значение для нашего проекта
Project Name polotskvet-site или другое свободное имя
Framework Preset Other
Root Directory Корень репозитория, ./; поле можно оставить по умолчанию
Output Directory public
Build Command Пусто; если нужно — включить Override и оставить пустым
Install Command Пусто; установка зависимостей отключена в конфигурации
Environment Variables Не нужны
Production Branch main, если GitHub создал основную ветку с этим названием

Root Directory оставь корнем репозитория. public задаётся в Output Directory. Файлы docs, inputs и design-assets не попадают в публикуемую папку сайта.

Нажми Deploy. Дождись статуса Ready. Если появится ошибка, открой Build Logs и посмотри её текст. Команда npm run build этому проекту не нужна.

6. Возьми ссылку для Романа

  1. Открой проект Vercel после успешного деплоя.
  2. Найди основной адрес в Domains / разделе production-развёртывания. Он будет выглядеть примерно как https://polotskvet-site.vercel.app; точный адрес назначит Vercel.
  3. Открой его в приватном окне браузера без входа в Vercel.
  4. Проверь логотип, фотографии, меню на телефоне, FAQ и прокрутку. Котик реагирует на мышь на компьютере; при уменьшении движения в настройках системы анимации отключаются.
  5. Отправь Роману этот проверенный адрес. Попроси открыть его с телефона в Беларуси: доступность из конкретной сети пока не проверена.

Если ссылка требует входа в Vercel, проверь, что скопирован production-домен, а не длинный адрес отдельного deployment. При Standard Protection основной production-домен открыт, а preview/deployment-ссылки защищены. Настройки находятся в Settings → Deployment Protection. Документация защиты.

Закрытый репозиторий GitHub скрывает исходники репозитория, но не делает опубликованный сайт приватным. noindex тоже не является паролем.

7. Как обновлять сайт

  1. На GitHub открой нужный файл, например public/index.html.
  2. Нажми значок карандаша Edit this file, внеси правку.
  3. Нажми Commit changes и сохрани изменение в основной ветке main.
  4. Vercel автоматически создаст новое развёртывание. Проверь его статус в Deployments и обнови сайт после Ready.

Тексты меняются в public/index.html, оформление — в public/styles.css, поведение — в public/app.js, картинки — в public/assets. Данные в inputs сохраняют контекст для дальнейшей работы, они не подставляются на страницу автоматически.

Если нужно отменить ошибочную текстовую правку, открой историю файла на GitHub, возьми прежний текст и сохрани его новым коммитом. Это также создаст новое развёртывание.

8. Перед рабочим запуском

  1. Добавить настоящий телефон и ссылки на выбранные мессенджеры. Заменить текущую заглушку записи в HTML/JS на рабочие действия; проверить звонок и сообщение с телефона.
  2. Утвердить домашние услуги, цены в BYN, условия выезда и часы связи. УЗИ пока указано только как специализация врача, не как услуга на дому.
  3. Уточнить образование и документы, если их нужно публиковать. Отзывы добавлять после появления настоящих отзывов именно этой практики.
  4. Выбрать и подключить домен через Settings → Domains. Vercel покажет DNS-записи для регистратора. polotskvet.by — обсуждавшийся кандидат, его доступность не проверялась.
  5. Для поискового запуска убрать все три ограничения индексации: метатег robots с noindex в public/index.html, заголовок X-Robots-Tag в vercel.json, запрет Disallow: / в public/robots.txt.
  6. В robots.txt разрешить обход; добавить canonical и sitemap с реальным доменом. Подготовить корректные структурированные данные о враче и практике, не выдумывая адрес клиники или рейтинг.
  7. Подключить Google Search Console и Яндекс Вебмастер; проверить страницы и отправить sitemap. План дальнейшего продвижения — в docs/PROJECT_CONTEXT.md.

Временная ссылка Vercel подходит для просмотра. SEO/GEO-продвижение этой версии ещё не запущено.

Страница без стилей или фотографий Загружены ли вложенные папки и public/assets; совпадает ли регистр имён; пути нельзя переименовывать по одному
